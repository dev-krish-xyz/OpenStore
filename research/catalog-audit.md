# OpenStore catalog research — October 5, 2026

The directory now has **60 projects**, including **48 names beginning with Open** and **38 additions** in this update.

## Scope and selection

Discovery covered the top 300 GitHub results for `open in:name stars:>1000 archived:false`, followed by specific searches for mature specialist applications and published user reviews. The exact discovery result is in [discovery.json](discovery.json). Official README documentation was retrieved for 44 additional candidates, including specialist projects below the broad search's star threshold. Their metadata is in [candidates.json](candidates.json). This is a broad curated sweep, not an exhaustive claim about every Open-prefixed project on the internet.

An app was included when its maintained official project offered a distinct, practical alternative use case, identifiable original branding, and an inspectable license. Libraries, specifications, learning lists, model-only repositories, duplicate forks, and unrelated OpenAI products were not automatically treated as apps. Stars measure repository interest, not users, quality, or satisfaction. No weighted “best” score was fabricated. Curated order groups useful applications rather than ranking unlike categories against each other.

## Important scope differences

- Open WebUI uses its current branding-restricted license and is labeled source-available.
- OpenWork's desktop/core is MIT; the ee/ directory uses a separate source-available license. OpenReplay likewise separates its commercial enterprise directory.
- OpenBB is now the Open Data Platform; it is not represented as a complete Bloomberg terminal replacement. Financial data and cloud services have separate licensing or costs.
- Open Interpreter's current repository focuses on a terminal coding agent. The old Python/computer-use product description is not carried forward.
- OpenCut's repository rewrite is separate from the classic browser editor. Planned desktop/mobile platforms are not listed as shipped.
- OpenDesign currently ships macOS/Windows binaries; Linux requires a source build.
- OpenVPN Community is distinct from commercial OpenVPN Access Server; Access Server reviews are not copied to Community.
- OpenHAB statistics belong to its core repository, not a fabricated sum across repositories. OpenWrt and OpenRGB use official GitHub mirrors, identified in their descriptions.
- OpenRA, OpenTTD, and OpenRCT2 engine licenses do not imply ownership of proprietary game assets. Asset requirements are explained.
